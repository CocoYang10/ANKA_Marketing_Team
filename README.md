# ANKA Marketing Intelligence

An internal marketing analytics and decision-support project developed during my internship with ANKA.

The project began as a weekly reporting dashboard and recommendation tracker. It is evolving into a system that connects marketing data, funnel measurement, data-quality checks, experiments, and evidence-backed recommendations.

## Current foundation

- GA4 ecommerce funnel and revenue-tracking audits
- Marketing data connectors and integration planning across Meta, MailerLite, and TikTok
- Normalized weekly reporting workflows
- Data-quality checks that separate a successful API connection from trustworthy data
- A recommendation tracker for owners, priorities, status, and results
- Safer handling of credentials, generated reports, and internal data

## Development plan

The longer-term system is organized into four layers:

1. **Measure** — establish a reliable view of sessions, funnel events, purchases, revenue, and channel performance.
2. **Diagnose** — identify tracking problems, conversion drop-offs, campaign changes, and product or landing-page opportunities.
3. **Act** — turn evidence into prioritized recommendations with owners, confidence, expected impact, and measurable outcomes.
4. **Learn** — connect recommendations to experiments and evaluate whether actions create meaningful improvement.

## Marketing Analyst Agent

The planned AI Agent will support the workflow by:

1. Pulling approved marketing and commerce data
2. Validating completeness and data quality
3. Calculating consistent KPIs
4. Detecting anomalies and funnel losses
5. Drafting recommendations with evidence and source context
6. Sending high-impact decisions for human approval
7. Reviewing experiment results and updating the decision history

The Agent is designed as a human-in-the-loop decision-support system. It will not automatically change budgets, publish campaigns, or treat missing data as reliable evidence.

## Privacy

This public repository describes the project direction and selected implementation work. Company data, credentials, customer information, internal reports, and sensitive operational details are not included.
